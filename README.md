# 🌿 TouchGrass AI

**Less scrolling. More living.** TouchGrass AI helps you step away from the
screen and discover a simple, safe outdoor adventure — powered by a local AI
model, so it works fully offline.

## Features

- Choose how much time you have outside (10, 20, or 30 minutes).
- Get nature-inspired activity ideas, either from built-in suggestions or
  generated by a local Ollama model.
- Start a countdown for your outdoor break and mark it complete.
- Track your progress (adventures completed and minutes outdoors), saved
  locally in your browser.

## Tech stack

- **Frontend:** a single static `index.html` (HTML, CSS, vanilla JavaScript).
- **Backend:** Node.js + Express (`backend/server.js`).
- **AI:** a local [Ollama](https://ollama.com) model (`qwen2.5:3b`) — no cloud
  API keys required.

## Prerequisites

- [Node.js](https://nodejs.org) (includes npm)
- [Ollama](https://ollama.com) running locally, with the model installed:

  ```bash
  ollama pull qwen2.5:3b
  ```

## Getting started

1. Install backend dependencies:

   ```bash
   cd backend
   npm install
   ```

2. Start Ollama (in its own terminal), then start the server:

   ```bash
   npm start
   ```

   If `npm start` is not defined, run the server directly:

   ```bash
   node server.js
   ```

3. Open your browser at:

   ```
   http://localhost:3000
   ```

## API

| Method | Endpoint          | Description                                        |
| ------ | ----------------- | -------------------------------------------------- |
| GET    | `/api/health`     | Health check — confirms the backend is running.    |
| POST   | `/api/activities` | Generate outdoor activities. Body: `{ "minutes": 20 }`. |

The `/api/activities` endpoint forwards the request to the local Ollama server
at `http://localhost:11434`.

## Notes

- Your progress is stored only in your browser's `localStorage`; nothing is
  sent to the cloud.
- No API keys or `.env` files are required. If you add one, it is already
  ignored by `.gitignore`.
